# SEA SOUL TOOL

Sea soul TOOL is a simple terminal-based demonstration script written in Python.  
It simulates certain automated actions such as "spam followers" and "mass report" in a visual way for educational and demonstration purposes.

The tool uses basic terminal animations, loading bars, and simulated processes to demonstrate how command-line interfaces and scripted workflows can appear in automation tools.

---

## Requirements

Python 3.x
Nano


---

## How to Run

1. Make sure Python 3 is installed.
2. Download the script.
3. Run it in the terminal
